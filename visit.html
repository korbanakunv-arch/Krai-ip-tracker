Tujuan link:

Memuat alamat tujuan…

Jika kamu menekan “Saya setuju”, aplikasi akan menyimpan alamat IP publik yang terdeteksi, waktu persetujuan, dan perkiraan lokasi (negara/wilayah/kota serta koordinat) dari IP untuk ditampilkan di dashboard pemilik link.

Untuk memperkirakan lokasi, alamat IP juga dikirim ke layanan eksternal ipwho.is. Lokasi IP bukan GPS; bisa meleset, terutama di jaringan seluler, VPN, atau jaringan bersama.

Jika menolak, aplikasi tidak menambahkan kunjungan ke daftar catatan tracker dan kamu tetap bisa menuju tujuan link. Penyedia hosting/jaringan tetap bisa memproses metadata koneksi mereka sendiri.

Jangan setuju jika kamu tidak nyaman dengan pemberitahuan di atas.
